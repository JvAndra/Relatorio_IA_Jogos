# 🎮 Jogo da Velha com IA (Minimax)

Este projeto implementa um agente invencível de Jogo da Velha (Tic-Tac-Toe) utilizando o algoritmo **Minimax**. O objetivo é demonstrar a aplicação de busca em árvore e recursão em jogos de soma-zero.

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
* [Python 3.x](https://www.python.org/downloads/)
* [Git](https://git-scm.com/downloads)

## 🚀 Como Rodar

Siga os passos abaixo para baixar e executar o jogo no seu terminal:

### 1. Clone o repositório
Abra o terminal (CMD, PowerShell ou Terminal do Linux/Mac) e digite:

git clone <https://github.com/JvAndra/Relatorio_IA_Jogos.git>

### 2. Acesse a pasta do projeto
Entre no diretório que foi criado (substitua nome-da-pasta pelo nome real do seu repo):

cd nome-da-pasta

### 3. Execute o jogo
Rode o script Python:

python tictactoe_ai.py
